# Customer Churn Prediction using Machine Learning

## Project Overview

This project predicts customer churn using Machine Learning techniques and analyzes customer behavior using data visualization.

The goal is to identify customers who are likely to leave the service and help businesses improve customer retention strategies.

---

## Dataset

Telco Customer Churn Dataset

Features include:
- Tenure
- Contract Type
- Monthly Charges
- Internet Service
- Payment Method
- Customer Demographics

Target Variable:
- Churn (Yes/No)

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
- Tableau
- Google Colab

---

## Machine Learning Models

1. Logistic Regression
2. Decision Tree
3. Random Forest

Random Forest achieved the best performance.

---

## Exploratory Data Analysis

- Churn Distribution
- Contract vs Churn
- Monthly Charges vs Churn
- Tenure vs Churn
- Correlation Heatmap
- Feature Importance Analysis

---

## Tableau Dashboard

Interactive dashboard created using Tableau to visualize churn patterns and customer behavior.

---

## Results

Key findings:

- Month-to-month customers have higher churn rates.
- Customers with shorter tenure are more likely to churn.
- Higher monthly charges increase churn probability.
- Random Forest outperformed other models.
